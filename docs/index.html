快速开始

四步接通设计与代码。

准备 Chrome、Figma Web、Node.js 22 / 24 / 26+，以及可正常使用的 Codex CLI 或 Claude Code。

  1. 01

    下载并解压

    从 Releases 获取完整安装包，放在长期保留的目录。

  2. 02

    加载 Chrome 扩展

    在 chrome://extensions 开启开发者模式，加载包内 chrome-extension 文件夹，并刷新 Figma。

  3. 03

    开启 MCP 并连接工具

    在 Design Bridge 面板的 Preferences → Agent integration 开启 MCP，允许访问本机 127.0.0.1。在安装包目录运行对应命令：

    node install.mjs codexnode install.mjs claude
    只使用其中一个工具时，只运行对应命令。
  4. 04

    选中节点，开始实现

    重启 AI 客户端或开启新会话，在 Figma 选中节点，然后发送上面的提示词。
