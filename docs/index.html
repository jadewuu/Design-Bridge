快速开始

四步开始使用。

需要 Chrome、Figma Web、Node.js 22+ 和 Codex 或 Claude Code。

  1. 01

    下载并解压

    从 Releases 获取安装包。

  2. 02

    加载 Chrome 扩展

    打开 chrome://extensions，加载包内的 chrome-extension 文件夹。

  3. 03

    开启 MCP 并连接工具

    在扩展设置中开启 MCP，再运行对应命令：

    node install.mjs codexnode install.mjs claude
  4. 04

    选中节点并发送

    用 Design Bridge 读取当前 Figma 选区并在本项目中实现。
